🌾 About Us
Ambai Industries is built on the belief that cattle nutrition shouldn't come with a compromise. We offer 100% safe, scientifically-formulated cattle feed crafted using high-quality raw materials and modern milling techniques.
By eliminating substandard ingredients and respecting nutritional science, we deliver a product that is not just feed, but a wholesome foundation for dairy farming success.

🛍️ Our Products
We specialize in premium cattle feed blends that cater to health-conscious dairy farmers and livestock owners alike:
- **Maize Makka Cattle Feed**: A perfectly balanced high-energy feed that promotes healthy weight gain and milk yield, giving cattle clean energy for peak performance.
- **Wheat Bran (Chokar)**: High-fiber, digestible wheat bran that ensures optimal gut health and rumen function. A perfect addition to your daily cattle diet.
- **Bulk & B2B Orders**: We also cater to large dairy farms, dealers, and agricultural cooperatives with specialized bulk packages and wholesale pricing.

🔒 Security & Environment Setup
Before deploying to production, follow the 5 security checks:
- **Secret Rotation**: Rotate all API keys (if applicable) in production environments. Never commit .env or .env.local files.
- **Admin Credentials**: Configure environment variables for any headless CMS or analytics platforms in your production hosting environment variables (e.g. Vercel Project Settings).
- **Security Headers**: Standard headers (X-Content-Type-Options: nosniff, X-Frame-Options: DENY, Strict-Transport-Security, Permissions-Policy) should be enforced via next.config.ts and middleware.
- **Rate Limiting**: Built-in API route rate limiting is recommended for endpoints handling bulk enquiries or dealer requests.
